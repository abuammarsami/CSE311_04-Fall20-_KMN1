# 🚗 Vehicle Subscription System - Database Project

## Project Overview

A comprehensive database management system designed for a vehicle subscription service, demonstrating advanced database design principles, normalization techniques, and complex SQL query implementation.

## 🎯 Business Problem

Design and implement a complete database solution for a vehicle subscription platform that manages:
- Vehicle inventory and specifications
- Customer subscription management  
- Insurance tracking and renewals
- Exporter and supplier relationships
- Financial transaction processing

## 🏗️ System Architecture

### Database Design Highlights
- **Fully Normalized Schema**: Implemented 3NF normalization to eliminate data redundancy
- **Referential Integrity**: Comprehensive foreign key relationships ensuring data consistency
- **Business Logic Implementation**: Complex constraints and rules enforced at database level
- **Scalable Design**: Modular table structure supporting future enhancements

### Core Entities
- **Vehicles**: Complete vehicle catalog with specifications and pricing
- **Customers**: Customer profiles and subscription history
- **Subscriptions**: Active and historical subscription records
- **Insurance**: Insurance policies and renewal tracking
- **Exporters**: Supplier and manufacturer information
- **Transactions**: Financial records and billing history
